# Regler for dette repoet

## Personvern – ingen personopplysninger i Git
Repoet er offentlig, og Git-historikken kan ikke enkelt slettes.

- Skriv aldri navn på spillere, foreldre eller andre personer i kode, kommentarer, commit-meldinger,
  testdata, README eller andre filer. Det gjelder også fornavn og «engangs»-kode.
- Spillerdata hører bare hjemme i Firebase (Firestore), bak innlogging og tilgangslister.
- Trenger en endring å treffe bestemte spillere (sletting, retting), gjør den i appen eller direkte i
  databasen – ikke med kode som inneholder navn.
- Testdata skal bruke oppdiktede navn, og ikke ligge i repoet.
- E-postadresser (utenom det som allerede står i `js/config.js`) skal heller ikke inn i repoet.
